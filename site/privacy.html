Project notes / October 24, 2026

Privacy, plainly.

The character lab

The lab processes text inside your browser. It does not send your input to a server, open entered addresses, or store inspection history. Refreshing the page resets the example.

The website

The website code includes no analytics scripts, advertising, cookies, or browser storage. Fonts and images are served with the website. Cloudflare hosts this website and may process ordinary request information, such as an IP address and the requested page, to deliver and protect it.

Links to other websites

GitHub and Unicode links take you to services with their own privacy policies. A GitHub account is needed to open an issue or participate there. GitHub Issues are public, so avoid posting passwords, private links, or other secrets.

Questions

You can contact the project through GlyphGuardian’s GitHub Issues.
